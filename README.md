# منصة المنظمة الأممية — استبيان عبر QR + شات بوت واتساب

مشروع **مجاني بالكامل** يعمل على جهازك المحلي (Node.js فقط، بلا XAMPP وبلا EasyPHP).

## 🧱 المكوّنات
- **Express + SQLite** → سيرفر خفيف + قاعدة بيانات ملف واحد (`data/platform.db`)
- **QR Code فريد لكل مشارك** → معرّف UUID بلا إيمايل ولا رقم هاتف
- **whatsapp-web.js** → شات بوت واتساب مجاني (QR أو Pairing Code)
- **html5-qrcode** → سكانار إدارية لتسجيل الحضور

## 📋 المتطلبات
- [Node.js](https://nodejs.org) نسخة 18 أو أحدث (تثبيت لمرة وحدة، مجاني)
- اتصال بالإنترنت فقط أول مرة (لتثبيت المكتبات وربط واتساب)

## 🚀 خطوات التشغيل

### 1) تثبيت المكتبات
```bash
cd un-platform
npm install
```

### 2) توليد المشاركين و QR Codes
استبدل `100` بعدد المشاركين، واستبدل الـ IP بعنوان جهازك على شبكة الـ WiFi
(اكتب `ipconfig` على Windows أو `ifconfig`/`ip a` على Mac/Linux لمعرفته):
```bash
node generate-qrcodes.js 100 http://192.168.1.10:3000
```
ستجد الصور في مجلد `qrcodes/` جاهزة للطباعة أو الإرسال.

> ⚠️ لا تستعمل `localhost` هنا — استعمل عنوان IP الجهاز، لأن هواتف المشاركين
> غير الجهاز نفسه ولازم توصل لنفس الشبكة (WiFi).

### 3) تشغيل السيرفر
```bash
npm start
```
افتح `http://localhost:3000` للتأكد أن كل شيء شغال.

### 4) تشغيل شات بوت واتساب (اختياري، في نافذة تيرمينال ثانية)

**الطريقة الكلاسيكية (مسح QR):**
```bash
npm run bot
```
سيظهر QR في التيرمينال، امسحه بواتساب: الإعدادات > الأجهزة المرتبطة.

**الطريقة بكود الربط (Pairing Code):**
```bash
node whatsapp-bot.js --pair +21612345678
```
سيظهر كود من 8 خانات، أدخله في واتساب: الأجهزة المرتبطة > ربط جهاز > ربط برقم الهاتف.

### 5) يوم الفعالية
- اطبع أو أرسل QR Code الخاص بكل مشارك (من مجلد `qrcodes/`)
- المشارك يمسح الـ QR بكاميرا هاتفه العادية → تُفتح صفحة الاستبيان مباشرة، معبأة بمعرّفه، بلا أي تسجيل دخول
- فريق التنظيم يفتح `http://<IP>:3000/admin-scan.html` من هاتف أو تابلت لتسجيل الحضور بمسح نفس QR

## 📊 متابعة الإحصائيات
```
GET http://localhost:3000/api/admin/stats
```
يعطيك عدد المشاركين، عدد من أجاب على الاستبيان، وعدد الحاضرين.

## ⚠️ ملاحظات مهمة
- **whatsapp-web.js غير رسمي**: لا تستعمل رقمك الشخصي إذا الحدث كبير، واستعمل رقم مخصص للمنظمة، وتفادى الإرسال الجماعي السريع لتفادي أي حظر مؤقت من واتساب.
- **الأمان**: بيانات المشاركين محفوظة محلياً في `data/platform.db` فقط — لا شيء يُرسل لأي سيرفر خارجي.
- **النسخ الاحتياطي**: انسخ مجلد `data/` بعد الفعالية للاحتفاظ بكل الإجابات.
- لو عدد المشاركين كبير جداً (+1000) أو الحدث في أماكن متعددة بنفس الوقت، يُفضّل الانتقال لاحقاً لسيرفر استضافة مجاني حقيقي (مثل Render أو Railway) بدل الجهاز المحلي.

## 📁 هيكل المشروع
```
un-platform/
├── server.js            # سيرفر Express + API
├── db.js                # إعداد قاعدة بيانات SQLite
├── whatsapp-bot.js       # شات بوت واتساب
├── generate-qrcodes.js   # توليد المشاركين + QR
├── public/
│   ├── index.html
│   ├── participant.html  # صفحة الاستبيان
│   └── admin-scan.html   # سكانار الحضور
├── qrcodes/               # (يُنشأ تلقائياً) صور QR لكل مشارك
└── data/                  # (يُنشأ تلقائياً) قاعدة البيانات + جلسة واتساب
```
